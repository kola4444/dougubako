# マラソン大会 表彰状メーカー

名簿（Numbers / Excel / CSV）を読み込むと、クラス全員分の表彰状を1つのPDFにまとめて作るWebアプリです。

## 使い方
1. iPadのSafariで公開URLを開く（ホーム画面に追加しておくと便利です）
2. **① 名簿・日付**：「ファイルを選択」で名簿を選び、日付を決める
3. **② 確認・編集**：全員分を確認し、必要ならフォント・大きさ・位置を変える
   - 「この賞状だけ」に切り替えると、1枚だけ変えられます
4. **③ PDF書き出し**：「PDFを作成する」を押し、「ファイル」に保存・共有・印刷する

名簿の1行目に「名前（または ふりがな・氏名）」と「順位」の見出しがあれば、自動で読み取ります。

## 園児の情報について
- 名簿の読み取りとPDFの作成は、**すべて使っている端末（iPad・Mac）の中で行われます**。
- 名簿の内容（名前・順位）が、インターネット上に送られたり保存されたりすることはありません。
- このページに置いてあるのは、アプリ本体（表彰状のひな形）だけです。
- **名簿ファイルやPDFは、ここにアップロードしないでください。**

## 印鑑について
- このページのアプリには、園の印鑑画像は**入っていません**（誰でも見られる場所に置かないため）。
- 初めて使う端末では、①の画面の「印鑑」欄にある「印鑑画像を読み込む」で、印鑑画像（`meisei_kakuin.png`）を選んでください。
- 読み込んだ画像は、その端末のブラウザの中だけに保存され、次回から自動で使われます。
- しばらく使わないと消えることがあります。そのときはもう一度読み込んでください。
- 印鑑画像は園のMacの「マラソン大会賞状」フォルダにあります。**このページ（GitHub）には絶対にアップロードしないでください。**

## 使っているフォントについて
賞状の楷書体には、無料フォント「AR PL UKai」（Arphic Technology）を使っています。
賞状で使う文字だけを取り出して、`index.html` に組み込んでいます。
このフォントは Arphic Public License で配布されているため、ライセンス文 `ARPHICPL.TXT` を一緒に置いています（削除しないでください）。

## アプリを直したいとき・置き直したいとき
- アプリは `index.html` の1ファイルだけで動きます。
- 元のファイルは園のMacの「マラソン大会賞状」フォルダにあります。
  - `表彰状メーカー.html`：Macでダブルクリックすると、そのまま使えます（iPadでは動きません）
  - `src/`：修正用の元ファイル
- GitHubで更新するときは、このページの「Add file」→「Upload files」で、新しい `index.html` を上書きアップロードします。
- GitHubが使えなくなった場合は、`index.html` を別のWebサービスに置けば、同じように使えます。
