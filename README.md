# どうぐばこ（試作版）

幼稚園の先生のための、賞状づくりやバスのコース計画などの道具をひとまとめにしたWebアプリ集です。
iPadのSafariで開き、「ホーム画面に追加」しておくと、アイコン1つから各アプリを使えます。

**公開URL：** https://dougubako.futureagencylab.com/

## ログインと利用許可証（試作・今は使っていません）

**今はログインなしで使う設定です。** どうぐばこを開くとすぐメニューが出て、全部のアプリが使えます。
ログインを使うときは、`common/license.js` の `const LOGIN_REQUIRED = false;` を `true` に変えるだけで、下のしくみが動きます（画面・しくみはすべて残してあります）。


- どうぐばこを初めて開くと、ログイン画面が出ます。ログイン後、この端末用の「利用許可証」（有効期限30日）を受け取ります。
- 期限まではインターネットがなくても使えます。期限が近づくと、どうぐばこを開いたときに自動で更新されます。
- 各アプリは端末の中の許可証を確かめるだけで、通信はしません。許可証に入っているのは園名・先生の名前・プラン・期限だけです。
- **試作版のため、本物のアカウントやサーバーはありません。** デモ用のアカウント（パスワードはすべて `demo1234`）と、右下の「試作の体験メニュー」で、期限切れ・解約・プラン変更などを再現できます。

## オフライン（ネットがない場所）での利用

- 一度インターネットにつながる場所でどうぐばこを開くと、アプリが端末に保存され、次からはネットがなくても開けます（`sw.js`）。
- マラソン大会 表彰状は、名簿の読み込みからPDF作成まで、ネットなしで使えます。賞状の書体は、一度使った書体が端末に保存されます（楷書体は最初から使えます）。
- バスルート計画は、画面は開けますが、地図の表示・道順の計算・住所検索にはネットが必要です。
- 書体と部品はすべてこのサイトに置いてあり、外部（Google など）からは読み込みません。

## 園児の情報について

- 名簿・印鑑・コースなど、アプリで使うデータは **使っている端末（iPad・パソコン）の中だけ** に保存されます。
- 園児の名前などの情報が、インターネット上に送られたり保存されたりすることはありません。
- このページに置いてあるのは、アプリ本体だけです。**名簿ファイル・PDF・印鑑画像は、ここにアップロードしないでください。**

## アプリ一覧

### 🏃 マラソン大会 表彰状メーカー（`marathon/`）

名簿（Numbers / Excel / CSV）を読み込むと、クラス全員分の表彰状を1つのPDFにまとめて作ります。

1. **① 名簿・日付**：「ファイルを選択」で名簿を選び、日付を決める
2. **② 確認・編集**：全員分を確認し、必要ならフォント・大きさ・位置を変える（「この賞状だけ」で1枚だけ変更も可）
3. **③ PDF書き出し**：「PDFを作成する」を押し、保存・共有・印刷する

- 名簿の1行目に「名前（または ふりがな・氏名）」と「順位」の見出しがあれば、自動で読み取ります。
- 印鑑画像はアプリに入っていません。初めて使う端末で、①の画面の「印鑑画像を読み込む」から読み込んでください（その端末の中だけに保存されます）。
- インターネットを使うのは、文字の書体を読み込むときだけです。名簿は送りません。

### 🚌 バスルート計画（`busroute/`）

園バスのコースを地図の上で作り、停留所ごとの時刻・所要時間・乗車人数と定員を確かめながら、コースの組み替えを検討できます。

- 初めて開くと「初期設定」が出ます。園の場所とバスを登録して始めます。
- 「サンプルで試してみる」で、サンプルのデータ（場所・停留所・コースは架空）で動きを試せます。
- コース別の時刻表＋ルートマップをA4で印刷・PDF保存できます。
- **地図・道順の計算・住所検索のためにインターネットを使います。** 送るのは位置（緯度・経度）と検索した言葉だけで、停留所名・人数・園児の情報は送りません。


### 準備中

- 🎖 なんでも賞状：いろいろな行事・場面で使える賞状を作るアプリ（メニューに「準備中」として表示）

## 公開のしくみ

- このリポジトリの内容を、Render（静的サイト）が自動で公開しています。
- ファイルを更新して GitHub に反映すると、1〜2分で公開ページも新しくなります。
- 設定は `render.yaml` に書いてあります（全ページ共通の安全のための設定）。
- 各アプリの通信先の制限（Content-Security-Policy）は、それぞれの HTML の先頭に書いてあります。

## ファイル構成

```
index.html        どうぐばこ（アプリを選ぶ画面）
render.yaml       Render の設定
sw.js             オフライン対応（アプリを端末に保存する仕組み）。更新したら中の VERSION を変える
manifest.webmanifest  ホーム画面に追加したときの設定
fonts/            書体（賞状で使う文字だけに減らしたもの。ライセンスは fonts/OFL.txt）
vendor/           地図の部品 Leaflet・並べ替えの部品 Sortable（それぞれ LICENSE.txt あり）
icon.png          ホーム画面のアイコン
icon.svg          アイコンの元データ（画面上のロゴにも使用）
common/
  license.js      共通部品：ログイン・利用許可証（試作のため、デモ用の仮サーバーを含む）
marathon/         マラソン大会 表彰状メーカー
  index.html
  ARPHICPL.TXT    楷書体フォントのライセンス文（削除しないでください）
busroute/         バスルート計画
  index.html
```

## 使っているもの

- 楷書体：AR PL UKai（Arphic Technology / Arphic Public License。ライセンス文は `marathon/ARPHICPL.TXT`）
- PDF作成：jsPDF（MIT）／ 表の読み込み：SheetJS（Apache 2.0）
- 書体：Noto Serif JP・Noto Sans JP・しっぽり明朝・Zen Old 明朝・クレー・佑字 肅・Zen 丸ゴシック（すべて SIL Open Font License 1.1）
- 地図：Leaflet（BSD-2）、国土地理院 地理院タイル ／ 並べ替え：Sortable（MIT）
- 道順の計算：OSRM（© OpenStreetMap contributors）／ 住所検索：国土地理院、OpenStreetMap Nominatim
